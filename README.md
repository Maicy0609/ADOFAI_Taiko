# 🥁 ADOFAI Taiko

将 ADOFAI (A Dance of Fire and Ice) 谱面文件 (`.adofai`) 转换为太鼓达人风格的滚动视频。

## ✨ 功能特性

- **谱面解析**：支持 `angleData` 和 `pathData` 两种谱面格式
- **速度模式**：
  - **随 BPM 变速**：滚动速度随谱面 BPM 变化，BPM 越快滚动越快
  - **固定速度**：所有音符以恒定速度滚动，不受 BPM 影响
- **最小音符间隔**（固定速度模式专属）：当相邻音符屏幕距离低于设定值时，自动加速该段滚动，确保音符间距不小于设定值，加速后回到原速度
- **重叠音符跳过**：自动跳过屏幕上完全重叠的音符渲染，避免视觉堆叠
- **GPU 硬件加速**：自动检测 AMD AMF / NVIDIA NVENC 编码器，支持 CPU 回退
- **背景音乐**：支持添加背景音乐并自动对齐谱面 offset
- **高清输出**：支持自定义分辨率、帧率、轨道高度等参数

## 🚀 使用方法

### 交互式运行

```bash
python main.py
```

按提示操作：
1. 输入 `.adofai` 谱面文件路径
2. 设置输出视频路径（可直接回车使用默认值）
3. 在参数调整菜单中配置各项参数
4. 选择 `[0]` 开始生成视频

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 基准速度 | 300 px/s | 100 BPM 时的滚动速度 |
| 变速倍率 | 1.0 | 全局速度倍率 |
| 帧率 | 60 fps | 输出视频帧率 |
| 视频宽度 | 1920 px | 输出视频宽度 |
| 轨道高度 | 160 px | 轨道高度（同时也是视频高度） |
| 背景音乐 | 关闭 | 可选择同目录下的音频文件 |
| 速度模式 | 随BPM变速 | `随BPM变速` 或 `固定速度` |
| 最小音符间隔 | 0（关闭） | 仅固定速度模式，相邻音符最小屏幕间距（px） |

### 速度模式详解

#### 随 BPM 变速（默认）

滚动速度与当前 BPM 成正比：

```
velocity = base_speed × (current_bpm / 100) × speed_mult
```

BPM 越高，音符滚动越快，密集段落音符间距自然缩小——与 ADOFAI 原版节奏感一致。

#### 固定速度

所有音符以恒定速度滚动：

```
velocity = base_speed × speed_mult
```

BPM 变化不影响滚动速度。适合希望所有音符均匀分布的场景。

#### 固定速度 + 最小音符间隔

在固定速度模式下，可设置最小音符间隔（如 5 px）。当相邻音符的屏幕间距低于此值时：

1. 自动加速该段滚动，使间距恰好等于设定值
2. 加速段结束后立即回到原速度
3. 不影响其他正常间距的音符

示例：设 `min_note_interval = 5`
- 正常间距 150 px → 保持不变
- 间距 3 px → 加速至间距恰好 5 px，然后回到原速度

## 🏗️ 项目结构

```
ADOFAI_Taiko/
├── config.py      # 全局配置（基准BPM、判定线位置、角度映射表）
├── chart.py       # Tile 数据模型 + .adofai 谱面解析
├── generator.py   # 视频生成核心（滚动计算、渲染、编码）
├── main.py        # 交互式入口
└── README.md
```

### 核心模块说明

- **config.py**：全局常量与 ADOFAI 角度字符到度数的映射表
- **chart.py**：`Tile` 类表示单个瓦片/音符，`load_adofai_tiles()` 解析谱面文件并构建完整状态
- **generator.py**：`TaikoAdofaiGenerator` 类负责预计算滚动距离函数、批量计算音符位置、逐帧渲染、视频编码输出
- **main.py**：交互式命令行界面，收集用户输入并调用生成器

## 🔧 技术细节

### 滚动距离函数

生成器使用**分段线性距离函数**将时间映射到全局滚动距离：

1. 遍历谱面构建速度段（每个 BPM 变化点为一个断点）
2. 在断点间以恒定速度积分，得到全局距离函数 `distance(t)`
3. 利用反函数 `t(distance)` 解析计算每个音符的出现时间

采用 NumPy 向量化 `searchsorted` 批量计算，避免了逐音符二分搜索。

### 最小音符间隔实现

在固定速度 + 最小间隔模式下：

1. 计算相邻音符在基础速度下的屏幕间距
2. 若间距 < `min_note_interval`，计算所需加速速度：`needed_vel = min_interval / dt`
3. 用"虚拟 BPM"编码该速度，内部切换为非固定速度模式构建距离函数
4. 加速段结束后插入回原速度的断点

### 重叠音符处理

渲染时跟踪上一个已绘制音符的 x 坐标，若当前音符与上一个坐标差 < 2 px，跳过绘制。计算开销可忽略不计。
